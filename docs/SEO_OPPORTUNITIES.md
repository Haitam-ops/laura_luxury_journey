## How to turn the plan into evidence

When GSC populates, export query/page pairs for the latest complete 28 days and preceding period; inspect 7-day changes with context. Group pages by trip/language. Review relevant impressions with weak CTR against actual snippets and positions. Inspect queries near page one rather than declaring a phrase easy from its wording. Multiple pages appearing for one query are not automatically harmful cannibalization; compare intent, canonical and conversion performance first.

Combine search demand with owner delivery strength, contribution margin and enquiry quality. If additional keyword tooling is later used, name the tool/date/country and label estimates. No tool-derived search volumes were obtained here. Get a backlink baseline from GSC Links when available and verify relevant referring sites manually; an optional independent tool can broaden coverage, but raw totals do not establish trust.

Create a new page only if it answers a distinct customer need not served by the current home/catalogue/trip/guides. Prefer one useful route comparison to many interchangeable desert articles. [Google people-first content guidance](https://developers.google.com/search/docs/fundamentals/creating-helpful-content).
